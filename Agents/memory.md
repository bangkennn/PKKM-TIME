## 1. 📋 INFORMASI PROYEK

- **Nama Proyek:** SiPANDU (Sistem Penelitian dan Pengabdian Dosen Terpadu)
- **Lokasi Direktori:** `d:\Code App\PPKM Time`
- **Tanggal Inisialisasi:** 2026-11-09
- **Tujuan Proyek:** Sistem Penelitian dan Pengabdian Dosen Terpadu (LPPM) STMIK TIME untuk Dosen dan Pengelola LPPM dengan Arsitektur Monorepo Fullstack.
- **Tech Stack:**
  - **Arsitektur:** Root Monorepo (NPM Workspaces) mengelola `frontend/` dan `backend/`
  - **Frontend:** Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4, Lucide React, Sonner, TanStack Query v5, Axios, Zustand v5, React Hook Form, Zod v4, class-variance-authority, clsx, tailwind-merge
  - **Backend:** Next.js 16 App Router API Routes (`src/app/api/`), TypeScript, REST API Handlers (`GET`, `POST`, `PUT`, `DELETE`, `PATCH`), Zod v4 validation
  - **Database Sentral:** MySQL / MariaDB via XAMPP & phpMyAdmin - Database: `ppkm_stmik_time`, Driver: `mysql2/promise` (Connection Pooling)

- **Backend Architecture (`backend/`):**
  - Terletak pada direktori `backend/` (Port dev default: 3001).
  - RESTful API & Autentikasi JWT:
    - `POST /rest/api/login` & `POST /resr/api/login`: Endpoint verifikasi login SiPANDU berbasis database MySQL dengan hash `bcryptjs`, penerbitan token JWT (`jsonwebtoken`), penyematan payload `groups` ('dosen' | 'lpmi' | 'admin'), dan penentuan rute redirect dinamis.
    - `POST /rest/api/change-password` & `POST /resr/api/change-password`: Endpoint pembaruan kata sandi akun dengan verifikasi hash lama dan enkripsi hash baru.
    - `GET/POST /rest/api/users` & `/resr/api/users`: Endpoint pengelolaan akun pengguna SiPANDU (list akun dengan pencarian & filter grup, pembuatan akun baru dengan hash `bcryptjs` dan pengecekan duplikasi username).
    - `PUT/DELETE /rest/api/users/[id]` & `/resr/api/users/[id]`: Pembaruan profil & peran grup, serta penghapusan akun dengan proteksi bawaan root administrator.
    - `PATCH /rest/api/users/[id]/reset-password`: Endpoint reset kata sandi akun spesifik oleh Administrator.
    - `GET/POST /rest/api/research` & `/resr/api/research`: Endpoint pengelolaan usulan proposal penelitian (list proposal dengan filter/search, ringkasan status LPPM & `isStage2Unlocked`, serta pendaftaran proposal baru dengan validasi Zod).
    - `GET/PUT/DELETE /rest/api/research/[id]` & `/resr/api/research/[id]`: Endpoint rincian proposal, pembaruan penuh usulan (seluruh field 4 langkah), dan penghapusan proposal yang belum diapprove LPPM.
    - `PATCH /rest/api/research/[id]/toggle-approval` & `/resr/api/research/[id]/toggle-approval`: Endpoint simulasi toggle persetujuan usulan LPPM (`pending_review` <-> `approved`) dan pembukaan gerbang Tahap 2 (`locked` <-> `in_progress`).
    - `GET/POST /rest/api/pkm` & `/resr/api/pkm`: Endpoint pengelolaan usulan proposal Pengabdian kepada Masyarakat (PKM) dengan validasi Zod, filter, pencarian, dan summary 3 tahapan.
    - `GET/PUT/DELETE /rest/api/pkm/[id]` & `/resr/api/pkm/[id]`: Endpoint rincian usulan PKM, pembaruan penuh usulan PKM 4 langkah, dan penghapusan usulan PKM.
    - `PATCH /rest/api/pkm/[id]/toggle-approval` & `/resr/api/pkm/[id]/toggle-approval`: Endpoint simulasi toggle persetujuan usulan PKM (Tahap 1, 2, 3) dan pengesahan status Selesai.
    - `POST /rest/api/pkm/[id]/kemajuan` & `POST /rest/api/pkm/[id]/akhir`: Endpoint pengunggahan laporan kemajuan & laporan akhir PKM.
    - `GET/POST /rest/api/templates` & `/resr/api/templates`: Endpoint pengelolaan berkas template resmi LPPM (list berkas dengan ringkasan kategori, serta unggah template baru dengan validasi ekstensi wajib `.docx` dan penyimpanan biner ke disk server `backend/uploads/templates/`).
    - `GET/DELETE /rest/api/templates/[id]` & `/resr/api/templates/[id]`: Endpoint rincian/unduh berkas binary template (membaca langsung dari disk filesystem) dan penghapusan berkas (membersihkan data MySQL sekaligus file fisik dari disk).
  - Next.js 16 App Router API Routes dengan koneksi connection pool `mysql2/promise` di `src/lib/db.ts`:
    - `GET /api/health`: Healthcheck status dan koneksi ping ke MySQL XAMPP (Service: SiPANDU API Service).
    - `GET /api/ppkm`: List data dari MySQL dengan filter kategori, pencarian LIKE parameterized, pagination, dan total count.
    - `POST /api/ppkm`: Validasi data via Zod, generate UUID, dan insert parameterized ke tabel `ppkm_entries`.
    - `GET /api/ppkm/[id]`: Detail data kegiatan berdasarkan ID dari MySQL.
    - `PUT /api/ppkm/[id]`: Full replace update data kegiatan di MySQL.
    - `PATCH /api/ppkm/[id]`: Partial update dinamis parameterized di MySQL.
    - `DELETE /api/ppkm/[id]`: Hapus data kegiatan dari MySQL.

- **Database / Storage (`database/`):**
  - MySQL / MariaDB via XAMPP (Localhost port 3306).
  - Database name: `ppkm_stmik_time`.
  - Tabel `users`: Manajemen akun Dosen, LPMI, dan Admin SiPANDU dengan password bcrypt.
  - Tabel `ppkm_entries`: Manajemen data kegiatan penelitian dan pengabdian masyarakat.
  - Tabel `research_proposals`: Manajemen usulan proposal penelitian, pagu anggaran, berkas PDF, serta status berjenjang LPPM (tahap 1, 2, 3).
  - Tabel `pkm_proposals`: Manajemen usulan kegiatan Pengabdian kepada Masyarakat (PKM), pagu anggaran, mitra, berkas proposal/kemajuan/akhir, serta status berjenjang LPPM (tahap 1, 2, 3).
  - Tabel `document_templates`: Penyimpanan berkas template resmi Word (`.docx`), kategori (proposal/laporan), ukuran berkas, dan payload binary base64.
  - File migrasi SQL: `database/schema.sql` (Termasuk seed default untuk dosen, lpmi, admin, dan sampel usulan penelitian serta PKM).

## 4. 🧠 KEPUTUSAN TEKNIS PENTING (KEY ARCHITECTURAL DECISIONS)

- **[ADR-001] Penerapan Protokol 3 Tahapan:** Setiap interaksi pengguna wajib melalui Tahap 1 (Analisis & Before-After) -> Tahap 2 (Menunggu Approval) -> Tahap 3 (QA, Zero Error & Security Audit).
- **[ADR-002] Standar Keahlian Senior:** Semua kode frontend, backend, dan testing wajib mengikuti standar baku di `Agents/skill.md`.
- **[ADR-003] Monorepo Root Separation:** Frontend UI dan Backend REST API dipisah dalam dua workspace independen (`frontend/` port 3000 dan `backend/` port 3001) untuk menjaga isolasi dependencies dan skalabilitas jangka panjang.
- **[ADR-004] Zero Vulnerability Policy:** Menggunakan versi Zod v4.6.7 yang telah dipatch untuk mencegah celah keamanan memory exhaustion (GHSA-mrhx-c7xc-m3w5).
- **[ADR-005] Migrasi ke MySQL XAMPP:** Menggantikan Supabase Cloud dengan MySQL lokal via XAMPP / phpMyAdmin untuk mengatasi batasan kuota. Backend mengimplementasikan connection pooling dan parameterized queries murni guna mencegah celah keamanan SQL Injection.
- **[ADR-006] Dual-Protection CORS & Next.js Rewrites Architecture:** Komunikasi klien browser diarahkan ke `/api` yang di-reverse proxy oleh Next.js Frontend ke Backend (`http://localhost:3001/api`). Backend juga dipasangi header CORS lengkap (`*`) agar dapat diakses baik melalui proxy internal maupun klien eksternal secara aman tanpa terblokir Same-Origin Policy.

## 5. 🔍 CATATAN PENTING & DEPENDENSI KHUSUS

- Lingkungan Operasi: Windows PowerShell (`npm.cmd` digunakan untuk eksekusi CLI).
- Root Scripts yang Tersedia:
  - `npm.cmd run dev:frontend` : Menjalankan Next.js frontend di port 3000
  - `npm.cmd run dev:backend`  : Menjalankan Next.js backend API di port 3001
  - `npm.cmd run build`        : Melakukan compile & build produksi frontend dan backend secara paralel
  - `npm.cmd run typecheck`    : Melakukan TypeScript type-checking ke seluruh workspace
- Konfigurasi Koneksi XAMPP:
  - Pastikan modul **Apache** dan **MySQL** di **XAMPP Control Panel** dalam status **Running**.
  - Buka phpMyAdmin di browser (`http://localhost/phpmyadmin`), klik tab **SQL**, salin dan jalankan seluruh isi file `database/schema.sql`.
